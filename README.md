# 台灣史年表：從荷西到今天

台灣史是主軸（8 個時期 → 事件泳道圖 → 事件卡，含來源、可信度與各方稱謂），李登輝線是可切換的深入視角。
首頁有整段台灣史（1624–今）的泳道總覽圖；目前只有「日治時期（1895–1945）」補完整（29 則事件、4 則背景專題，已經審查），其餘時期會逐期擴充。

**開發者／接手者請先讀 [`CLAUDE.md`](CLAUDE.md) 與 [`docs/ROADMAP.md`](docs/ROADMAP.md)。** 原始碼在 `src/`，`python3 build.py` 產生發布用的 `index.html`。

以下是原本的「李登輝年表」內容說明：

## 說明

- 單一 `index.html`，無建置步驟，直接以 GitHub Pages 發布。
- 事件內容與解析是根據公開史料整理的學習筆記，不是書中原文。仍有爭議的說法（二二八死亡人數、蔣經國是否屬意李登輝接班等）在頁面上有註明。
- 筆記存在瀏覽器的 localStorage，只在本機保留。
- 字型：Noto Serif TC、Noto Sans TC（Google Fonts）。
