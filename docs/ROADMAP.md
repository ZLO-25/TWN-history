## 新增：中華民國大陸時期（同期中國大陸軌道）
已收 1912–1948 的政權分界事件。尚未收：辛亥革命、五四、中共成立、九一八、西安事變、抗戰全面爆發與勝利、國共內戰關鍵節點。原則：只收「對理解台灣同時期統治政權有幫助」的節點，一律標 `ctx:"中國大陸"`，不要把站台變成中國通史。

## 擴充一個時期的步驟
1. 列出該時期 20–30 則事件與 3–4 則專題清單，交使用者看過範圍再開工（太大就先問）。
2. 研究（見 CLAUDE.md 品質流程第 1 點），產出 JSON 放 `docs/`（例如 `docs/p4_events.research.json`），保留來源與歧見。
3. 轉成 `H_RAW` 條目（短標籤 `s`、`bg` 連結），專題寫進 `src/bgdata.js`。
4. 全期泳道圖會自動出現新事件圓點；「待擴充」字樣在該時期有事件後自動消失。
5. 審查 → 修正 → build → `tests/smoke.py` → 部署 → 請使用者確認。
