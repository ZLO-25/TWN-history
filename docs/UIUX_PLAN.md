# UI/UX 改善規劃（2026-11-15）

目的：讓第一次來的人（以及拿網站去教別人的人）更快知道「這是什麼、從哪開始、怎麼看」，並讓長文字更好讀。
**只動介面（`src/template.html` 的 CSS／HTML／前端 JS 與 `tests/smoke.py`），不改任何歷史內容（`history.js`、`bgdata.js`、`data.js`、`people.js`、`threads.js` 一個字都不動）。**

## 不可推翻的既有決定
- 網站標題「中華民國、台灣史」。
- 三層下鑽：全期泳道圖（在上）→ 8 時期方塊 → 時期泳道圖 → 事件卡；順序不變。
- 三張泳道圖共用 `lcMake`／`lcRender` 與 `.lc-*` 樣式；不為單張圖另寫樣式；泳道密集時短標籤只顯示月份。
- 每期「這個時期要記住的 3 件事」、搜尋、學習路徑（30 分鐘／3 小時）、講課模式、翻卡複習、人物、跨期主線全部保留，功能不變。
- 七個分頁與其順序、`data-view` 值、網址 hash 都不變。
- 事件卡在 ≥1100px 固定右側、較窄從下方滑出；<700px 時期圖改直式列表。
- 中性用語；可信度標籤（✓已查證／≈常見說法／⚑有爭議）樣式語意不變。

## 現況問題（依截圖評估，桌機 1400px、手機 400px）
1. 首屏：副標還在講李登輝線的數字（111／23／27），和「台灣史是主軸」不符；桌機要捲 450px、手機要捲 490px 才看到圖。
2. 搜尋框在桌機只有約 190px 寬，placeholder 被截斷。
3. 「學習路徑／講課模式」是三個小灰膠囊，最重要的教學入口不顯眼。
4. 使用說明是一段灰色長句；全期圖下方說明是一大段文字，把 8 個時期方塊往下推。
5. 七個分頁平鋪：看不出「李登輝／民主接力／政治手腕」是同一組深入視角；手機分頁被切掉、沒有可橫滑的提示。
6. 內文 15px、說明 14px 灰字，對投影教學與年長讀者偏小；沒有字級切換。
7. 事件卡的歧異說明整段用紅字（`.hnote`），像錯誤訊息、長段難讀；且非爭議事件的補充也掛 ⚑。
8. 「李登輝」分頁的說明文字與「顯示全部事件」貼在視窗最左邊，和上方置中的標題／分頁沒對齊。
9. 時期方塊沒有 hover／可點提示，和泳道圖的時期色帶沒有視覺關聯。
10. 手機：圖例膠囊＋縮放鈕佔三列；膠囊點擊高度約 30px，偏小。

## 修改項目（執行者逐項做）

### A. 首屏重整（`<header class="masthead">` 與 `#v-history` 開頭）
A1. 副標改為：`從 1624 年到今天，用一張圖看懂誰在什麼時候統治台灣；每則事件都附來源與可信度。`
   原本的李登輝數字句（含 `<b id="total">`、`<b id="mtotal">`、`<b id="cktotal">` 三個元素，JS 會填值，**id 必須保留**）移到 `#v-overview` 的 `.intro` 最後面，寫成「李登輝線共 … 則事件，… 則附政治手腕解析，… 則標出蔣經國的影響。」
A2. `#v-history` 開頭順序改為：搜尋框 → 「從這裡開始」三張行動卡 → 三步驟提示 → 全期圖。刪掉原本那段 `.intro` 長句（內容由三步驟取代）。
A3. 搜尋框：`.hsearch input` 寬度 100%，高度 ≥44px，左側加放大鏡圖示（CSS 背景或 inline SVG，不用外部圖檔）。placeholder 桌機維持原文，手機可縮短為「搜尋人名、事件、年份」。
A4. 「從這裡開始」：把 `.paths` 改成 3 欄格狀行動卡（手機 1 欄或橫向不擠），**保留原本三個按鈕的 id（`goPath30`、`goPath180`、`lectureBtn`）與行為**。每張卡：標題＋一行說明。
   - `goPath30`「30 分鐘路徑」— 說明「第一次看：只走最關鍵的事件」
   - `goPath180`「3 小時路徑」— 說明「完整走一遍八個時期」
   - `lectureBtn`「講課模式」— 說明「投影教學用：放大字、← → 逐則切換」
   注意 `setLecture()` 會用 `textContent` 改寫 `#lectureBtn`（1103 行附近）；卡片若包含子元素，請改成只改標題那個 span，並保留 `aria-pressed`。講課模式下（`body.lecture`）其他兩張卡與說明要隱藏，只剩「離開講課模式」，既有 CSS 選擇器（247 行）要一併更新。
A5. 三步驟提示（一次性、可關閉）：`① 選時期　② 看泳道圖　③ 點事件看來源與可信度`，三個小步驟橫排（手機可換行），右側「知道了 ✕」按鈕；關閉狀態用既有 `store`（已包 try/catch）存 `hintOff=1`，之後不再顯示。講課模式下隱藏。

### B. 導覽
B1. 分頁分組：在「李登輝」分頁前加一個不可點的分隔（細直線），並讓「李登輝／民主接力／政治手腕」三個分頁共用一條淡色底或上方小字「李登輝視角」，讓人看出是同一組。不改 `data-view`、順序、`role`。分隔元素要 `aria-hidden="true"`，且不能被 `.tab` 的選擇器（JS 用 `.tab[data-view]`）誤抓。
B2. 手機橫滑提示：`.tabs` 右緣加漸層遮罩（還能往右滑時才顯示），並在切換分頁時把被選的分頁 `scrollIntoView({inline:"center",block:"nearest"})`。注意 `.tabs` 是 `position:sticky`，遮罩用包一層或 `mask-image` 都可，但不可破壞 sticky。

### C. 全期圖與時期方塊
C1. `.hallnote` 那一大段改包進 `<details class="hallhelp"><summary>怎麼看這張圖</summary>…原文不變…</details>`，預設收合。
C2. 時期方塊 `.hb`：加 hover／focus 樣式（邊框變深、微微上浮）、右上角「›」提示、標題字 17px；頂部加一條 3px 色條（用 `--seal`，被選中時加粗）。不改方塊內文字與資料。
C3. 「整段台灣史一張圖」標題與 8 個方塊之間加小標「八個時期（點一個進去看）」。

### D. 事件卡可讀性（`renderHCard` 附近，1036–1038 行）
D1. `.hnote` 改成淡色底的說明框：文字用 `--ink`，左邊 3px 邊線，內距 8–12px，圓角 6px，字級與內文相同。
D2. 開頭標籤依可信度：`h.conf==="disputed"` 顯示「⚑ 各方說法不同」（標籤用 `--seal` 粗體）；其他顯示「補充說明」（標籤用 `--muted` 粗體），不再一律掛 ⚑。同期背景提示（`ctxNote`）用同一種框但標籤為「同期背景」。**說明文字本身一字不改。**
D3. 事件卡內段落行高 1.75、段距一致；「前因／影響」小標與內文間距統一。

### E. 字級與易讀
E1. 全站基準字 15px → 16px（`body`），`.intro`、`.hb small` 等 12–14px 的說明字各加 0.5–1px；泳道圖內的字（`.lc-*`）**不動**，避免排版重算後標籤溢出。
E2. 在深淺色按鈕旁加字級切換鈕（`id="fsz"`，顯示「字」或「A＋」，`aria-label="切換字級"`）：一般 → 大（基準 18px）→ 一般，狀態存 `store` 的 `fsz`；作法是在 `<html>` 加 `data-fsz="lg"` 並用 CSS 調 `body` 字級。大字時泳道圖仍不變。
E3. 所有 `.chip` 與圖例膠囊在觸控裝置（`@media (pointer:coarse)`）最小高度 40px。

### F. 對齊修正
F1. `#v-overview` 目前整段放寬到 1500px，導致 `.intro` 與 `.ovbar` 貼左。改成：說明與按鈕列維持 780px 欄寬置中（和標題、分頁對齊），只有圖表那一塊 `.lc-split` 用和台灣史相同的 `.wide` 做法放寬。**不可用 `transform`**（底部事件卡是 `position:fixed`，見 CLAUDE.md 踩雷）。改完確認 ≥1100px 時右側事件卡仍在圖旁、<1100px 仍從下方滑出。

### G. 手機細節
G1. `.lc-tools` 在 <700px：圖例改單列橫向捲動（不換行），縮放鈕靠右同列或下一列，總高度不超過兩列。這是共用元件樣式，三張圖一起生效。
G2. 確認 400px 寬沒有水平捲軸（`document.documentElement.scrollWidth<=innerWidth`）。

H1. `tests/smoke.py` 既有檢查全部要過（目前 89 項 PASS）；不得刪除或放寬既有檢查。若既有檢查因為元素搬家而需調整選擇器，只改選擇器、不改檢查意圖。
